# Contributing to Yayp Communication AI Assistant

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/Yayp-communication.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Install dependencies: `pip install -r requirements.txt`

## Development

1. Make your changes
2. Add tests for new functionality
3. Run tests: `pytest tests/`
4. Ensure code quality: `flake8 ai-assistant/`

## Commit Messages

Use clear, descriptive commit messages:
- `feat: Add new feature`
- `fix: Fix bug in module`
- `docs: Update documentation`
- `test: Add tests for feature`

## Pull Request Process

1. Update documentation if needed
2. Add tests for new features
3. Ensure all tests pass
4. Create a descriptive pull request
5. Wait for review and address feedback

## Code Style

- Follow PEP 8 guidelines
- Use type hints for function arguments and returns
- Add docstrings to all functions and classes
- Keep functions focused and small

## Reporting Issues

Use GitHub Issues to report bugs or suggest features. Include:
- Clear description
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Environment details
